# Мастерская и альбом

Спецификация от 18.10.2026. «Рисунок» — сохранённый объект, собранный из готовых частей.

## Маршруты и категории

Альбом → Собрать рисунок → Башня / Сооружение. Башня: выбрать основу, установить оружие, проверить. Сооружение: семейство, четыре категории состава, проверка. «Разобрать состав» открывает редактор компонента без потери родительского черновика. Возврат без сохранения оставляет исходную башню прежней.

| Объект | Обязательные категории |
|---|---|
| Основа | Рамка, корпус, броня, подача, поворот |
| Оружие | Механизм, ствол/головка, прицел/датчик, магазин/кассета, спуск |
| Сооружение | Основание, функциональный блок, оболочка, оснащение |

«Без брони» и «Без оснащения» — явные нейтральные определения. Первое оружейное крепление обязательно, дополнительные опциональны. Рамки задают 2/2/1/3 крепления. Число креплений не увеличивается рисованием или растягиванием корпуса.

## Экран сборки

Крупный объект, выбранные детали, цена в штрихах, нагрузка/вместимость и изменения параметров видны одновременно. Каталог фильтруется по совместимости; «Показать недоступные» раскрывает будущие открытия. Недоступная деталь открывает условия покупки и не устанавливается. Причина несовместимости конкретна: «Этот ствол подходит только пулемёту и пробою».

У детали видны категория, роль, совместимость, требуемый уровень, цена открытия, доплата постройки и нагрузка. Магазин отдельно показывает объём, интервал выстрелов и время смены. Ремонт и генерация подписываются HP/с и штр./волну. Декор не участвует в расчёте.

## Проверка и полигон

Имя до 48 символов, состав, цена, роль и предупреждения. Кнопки: На полигон, Сохранить рисунок, Отмена. Сохранять можно только полный допустимый состав из открытых частей. Компонент сохраняется в библиотеку основ/оружия; «Сохранить и выбрать» меняет родительскую башню только после успешной записи.

Полигон использует те же resolver и боевые системы: одиночная цель/линия/группа для оружия, повреждённый союзный объект для ремонта, ускоренные волны без наград профилю для генератора. Бюджет и сценарий подписаны. Пауза и повтор пробы не меняют альбом.

## Сохранение

Рецепт содержит ID и версии определений. Страница альбома хранит свою ревизию и снимок зависимостей. «Сохранить как вариант» создаёт новый ID. Удаление компонента из библиотеки не ломает готовую башню. Удаление назначенного рисунка показывает затронутые слоты и очищает их только после успешной записи.

Ошибка IO оставляет черновик и не меняет опубликованные альбом, золото и набор. Повторная попытка идемпотентна. Нельзя показать «Сохранено» до успешного commit профиля.

## Восемь слотов

Назначение: рисунок → один из 8 общих слотов. Повторное назначение того же ID предлагает перенос, а не дубликат. В подготовке весь набор виден: 4×2 на 4:3; на широком экране допустимы 8×1 или 4×2. В бою клавиши 1–8 отвечают за слоты; материал и цвет имеют отдельные действия.

## Обязательные состояния

| Состояние | Поведение |
|---|---|
| Пустой альбом | Восстановление бесплатного набора без потери золота |
| Недостаток уровня | Текущий и требуемый уровень, прогресс XP |
| Недостаток золота | Цена и недостающая сумма; состав прежний |
| Покупка | Одно списание; право во всех совместимых каталогах |
| Перегрузка | Превышение и вклад частей; сохранение/полигон недоступны |
| Очередь + барабан | Несовместимость, предложение штатной обоймы |
| Неизвестный ID/версия | Диагностика без молчаливой замены |
| Ошибка записи | Повторить / вернуться к черновику |
| Только поддержка в наборе | Объяснение необходимости атакующей башни |
