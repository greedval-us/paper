# Документация «ДЕРЖИ ЛИНИЮ»

Актуальные руководства по проекту Unity **6000.5.7f1**. В игре: три тетради и девять миссий, составные башни и четыре семейства сооружений, восемь боевых слотов, золото и опыт, профиль v9. Общий стиль — тёмный полевой блокнот: «Бумажная механика», «Чернильная стая», панели «Полевой штаб».
