# Документация «Держи линию»

**Перенесены главное меню, карта, подготовка, основа башни, оружие и настройки (01–05, 22).** Экраны 04–05 используют существующие рисунки деталей из общего атласа; оружие показывает текущую сборку, крепления и семь карточек. Постройки, враги, окружение, эффекты и значки используют новый рисунок синей ручкой. Композиции экранов 06–21 и 23–28 ещё предстоят; следующий экран — 06 «Рисунок». Обновление боевых ассетов не означает готовность HUD 15–17. [Порядок реализации](Implementation-Roadmap.md) отделяет готовую часть от оставшейся работы; технические справочники описывают действующие игровые правила.
