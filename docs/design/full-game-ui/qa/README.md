# Проверка дизайн-альбома

Объект проверки — HTML-эскизы, не игровая сборка Unity.

- `layout-report.json`: 90 сочетаний экранов, разрешений и масштаба текста; проверены ошибки JavaScript, горизонтальное переполнение основных контейнеров и выход непрокручиваемых кнопок/полей за окно.
- `interaction-report.json`: 17 проверок навигации, размеров, фильтрации, раскрытия параметров и статистики, блокировки фона, доступных названий кнопок, безопасного фокуса и Escape.
- `sheet-0.png` … `sheet-4.png`: обзорные листы всех 30 макетов.
- `overview.png`: шесть основных экранов для быстрого просмотра.
- `album-viewer.png`: внешний навигатор дизайн-альбома.
- Изображения с разрешением и масштабом в имени — адаптивные варианты меню, мастерской и боя.

Ручной просмотр: все 30 макетов на обзорных листах; дополнительно главное меню, рисунок, бой, основы, мортира, полигон и компактные варианты в полном размере. Исправлены размеры SVG в карточках и специальных редакторах, вертикальная плотность, противоречивая готовность пустого ствола, доступные имена и возврат из настроек в контекст боя.

Прокрутка длинных сводок, справки, альбома и настроек допустима. Проверка переполнения не заменяет последующее тестирование Unity Canvas, реального рисования, симуляции, сохранения и баланса.

Для повторения: запустить `node serve.cjs` из родительской папки, открыть локальный альбом через Playwright CLI и выполнить `run-code --filename .../qa/export.cjs`, затем `contact.cjs` и `interactions.cjs`. Скрипты сохранены с абсолютным путём этого проекта; при переносе обновить `root` и `base`. `python build-package.py` проверяет отчёты и собирает ZIP.
