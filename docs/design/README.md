## Правила переноса

Эскизы определяют композицию, бумагу, рисунок ручкой и характер деталей. Цены, ресурсы, ограничения и состояния берутся из игровых данных. Растровые цифры иллюстративны: экран 15 не показывает отдельную карточку ремонта, экран 14 содержит условную полоску прочности, экран 13 показывает не все допустимые направления веера. Эти ограничения описаны в [проверке комплекта](game-concept-art-2026-10-16/qa.md).

Игровые подписи, значения, кнопки и области ввода остаются самостоятельными элементами Unity. Фоны и декоративные логотипы — отдельные ассеты без запечённых игровых чисел. Иллюстрации показываются целиком с собственным соотношением сторон; дополнительное пространство заполняется бумагой.

Настройки 22 дополнены выбором разрешения с текущим размером и кнопкой «Применить». Изменение выбора само по себе не меняет экран. На карте, подготовке и в настройках основные действия доступны без прокрутки.

Проверка галереи и целостности PNG подтверждает сохранность эскизов. Реализация подтверждается снимками Unity и проверкой работающих действий.
