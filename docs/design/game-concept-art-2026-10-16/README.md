# Полные эскизы игровых экранов

**Обновлено 18.10.2026.** [Открыть галерею](index.html). По прежнему адресу находятся **все 28 исходных экранов, отредактированные под составной альбом**, ещё 2 экрана сборки и 3 листа объектов — всего 33 изображения.

Сохранены главное меню, карта, подготовка, мастерская, бой, пауза, настройки, справка, победа, поражение и служебные состояния. Синяя ручка, тёплая клетка, замок и исходные композиции сохранены. Холст заменён сборкой готовых частей; набор содержит до 8 общих слотов; платные детали требуют уровня и однократной покупки за золото.

Это основная художественная галерея. [Интерактивный прототип](../album-assembly-2026-10-17/index.html) дополняет её расчётами и переключением состояний. Оба комплекта описывают будущий интерфейс; изменения Unity-сцен в эту работу не входят.

## Просмотр и источники

Откройте index.html в браузере. Фильтры группируют экраны; клик увеличивает изображение; стрелки листают, Esc закрывает просмотр. Галерея работает локально без сети.

Числа соответствуют [балансу v1](../../balance/README.md). Меню партии и межволновые бонусы опираются на текущую игру; новый каталог и опыт — целевой дизайн. Указанный на изображении набор 8/8 является примером: допускается меньше рисунков, если есть атакующая башня. Полигон не выдаёт вымышленные результаты.
