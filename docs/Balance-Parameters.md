# Источники параметров

Актуальная проектная модель: [54 детали и формулы](Component-Stats-and-Abilities.md), [Excel и методика](balance/README.md). Новые значения ещё не импортированы в Unity.

## Основная игра сейчас

Источник: [PlayerBalance.asset](../Assets/PaperDefense/Configuration/Game/PlayerBalance.asset) → [PlayerRules.asset](../Assets/PaperDefense/Configuration/Game/PlayerRules.asset) → [PlayerContent.asset](../Assets/PaperDefense/Configuration/Game/PlayerContent.asset). Проверенный снимок разрешённого каталога: [current-runtime.json](audit/2026-10-17-album/current-runtime.json). Снимок получен через Unity из рабочего asset, а не из констант Historical/Target.

| Параметр | Текущее значение | Новое решение |
|---|---:|---|
| Профиль | v7 | v8 с явной миграцией |
| Слоты | 4 | 8 общих |
| Стартовый ресурс | 640 штрихов | 640 |
| Завершённая волна | 8 золота | 8 золота + 10 XP |
| Победа | 30 золота | 30 золота + 40 XP |
| Полная партия из 8 волн | 94 золота | 94 золота, 120 XP |
| Уровень игрока | Нет | 1–8 |
| Обоймы | Нет отдельного состояния | Новый цикл выстрелов и перезарядки |

Существующие стартовые башни сохраняют базовую цену и непрерывный DPS. Новые коэффициенты, генератор, отдельные детали и прогрессия — расчётное предложение. Урон по площади и пробитие нельзя оценивать одним множителем DPS без сценария расположения целей.

## Границы источников

`Historical.asset` и `Target.asset` — отдельные пресеты для технических сравнений. Старый экспортёр `Tools/BalanceWorkbook` работает с ними; его таблица не заменяет основной баланс. Новый комплект строит `Tools/AlbumDesign2026` из снимка основной игры и явных проектных добавлений.

`BalanceValidation.Validate` проверяет конфигурацию до старта. `GameSession`, `WeaponSystem` и `TrialRunner` используют снимки; изменение исходного asset не должно менять уже начатый бой. Порядок слияния записей описан в [архитектуре контента](Content-Architecture.md).

Числовой источник новой модели — [album-balance-v1.json](balance/album-balance-v1.json). При изменении данных пересобрать Excel и данные галереи, затем повторить проверки. Изменения в Excel для подбора чисел не импортируются в JSON или игру автоматически.
