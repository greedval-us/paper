# Сцены механик: стенды удалены

Отдельные 27 сцен из `Assets/PaperDefense/Scenes/Tests`, общий экран MechanicsHub, прежняя техническая PaperDefense и сцена ContentAcceptance удалены вместе с генераторами, настройками стендов и runtime-обвязкой. Этот документ сохранён как отметка изменения входов проекта.

Для запуска откройте [PaperDefenseGame.unity](../Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity) через **Paper Defense → Game → Open player game** или **Paper Defense → Открыть игру** и нажмите Play. Это единственная сохранённая сцена игры и единственная сцена сборки. Игровая мастерская и полигон остаются доступны из основного маршрута.

Автоматические проверки ядра, игрового маршрута, профиля, графики и данных сохранены. Сценарии Pressure, NumericBalance и InkLoop выполняются в Editor-only сборке Validation; данные Content/Acceptance используются автоматическими тестами без отдельной сцены. Проверки состава удалённых стендов и переходов hub убраны.

[Датированные отчёты](validation/README.md) сохраняют историю прежних проверок. Эскизы в `docs/design`, исходники ArtSource и игровые арт-ресурсы сохранены. Наличие автоматических тестов не означает их успешный запуск после очистки.
