# Пошаговая мастерская — вариант A

**Основание:** пользователь выбрал эскиз A «Чистый лист» и прямо поручил реализацию. Работа в текущем подключённом к Unity проекте, исходный HEAD `671ed0e`, дерево чистое. Unity 6000.5.7f1, uGUI, существующие Core/Application. Дополнительное согласование реализации не требуется.

**Цель:** игровой вход ведёт через «Основа → Оружие → Рисунок → Проверка», сохраняя механику чертежей. Минимум текста по умолчанию, подписи у основных действий, векторные иконки и подсказки при наведении/фокусе, подробности раскрываются. Альбом доступен отдельно. Четыре боевых слота остаются на подготовке.

## Контракт

- Полотно 1600×1000 с существующим CanvasScaler. Палитра варианта A: #FAFBFD, #EDF3FA, #243A5C, #315FDB, #5A907B. Основной шрифт встроенный sans с кириллицей, NotebookHand только заголовки.
- Верхняя строка 0–92, шаги слева x24..274, основная область x300..1140 y110..890, сводка x1170..1570, нижние действия y920..976. Подсказка поверх UI без перехвата ввода.
- Новый WorkshopWizard подключается в реальном PlayerGameRoot через WorkshopHud.UseGuidedFlow. Изолированные технические режимы мастерской продолжают использовать свои проверочные панели.
- Данные из RunController.Content/Workshop, никаких жёстких списков оружия. Закрытые детали видны и открываются только явной покупкой, с ценой. Недопустимые переходы показывают причину, не сохраняют/списывают ресурсы.
- Шаги назад сохраняют черновик. После изменения основы/оружия последующая готовность пересчитывается. Рисование обязательно валидно для сохранения. Нельзя пропустить непосещённый шаг. Альбом не теряет рабочий черновик при закрытии.
- Проверка: мини-проба одного ствола и возможность общего полигона; сохранить в альбом отдельной явной кнопкой. Неудача сохранения оставляет черновик и шаг. Назначение в слот — отдельная команда.
- Существующие редакторы отпечатка, веера и усиления доступны из дополнительных настроек. Цифры берутся через PreviewBlueprint; детали «до → после» остаются доступными.
- Все новые строки через `UserText` и Tools/user-texts.json. Агенты складывают дополнения в отдельные JSON в Library/CodexGuidedWorkshop; общий manifest обновляет координатор.
- Только координатор использует Unity tools и запускает тесты, после завершения записей Assets всеми участниками.

## Разделение

1. `WorkshopUi.cs`, `WorkshopIconGraphic.cs`: общие элементы, иконки, подсказки. API описан в сообщении исполнителю.
2. `GuidedDrawingPanel.cs`: адаптация DrawingEditSession/Canvas к A, тулбар, слои, чернила, сводка, раскрываемые подробности, заготовки и мини-проба. Родительский wizard владеет навигацией/сохранением.
3. `WorkshopWizard.cs` + альбом: шаги основы/оружия/проверки, последовательность и покупки, интеграция WorkshopHud/PlayerGameRoot/PlayerShell.
4. Тесты потоков, независимое ревью, полные EditMode/PlayMode, реальные рендеры PlayerBalance при 1600×1000 и уменьшенном разрешении, инструкция.

## Особые проверки

Пустая/невалидная геометрия; третье крепление и повторяемые модули; смена основания на меньшую вместимость; закрытые детали/недостаток золота; ошибка записи профиля; открытие альбома/смена страницы во время незавершённого штриха; возврат из других игровых страниц; локализованные длинные подписи; подсказки под модальными окнами; невидимые панели не ловят raycast.
