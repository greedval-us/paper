# Надёжность профиля и общий баланс — план этапа 1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans after approval. Steps use checkbox syntax for tracking.

**Goal:** Исправить ложный успех сохранения/восстановление backup и передать актуальные боевые настройки в полигон без изменения баланса.

**Architecture:** Core сохраняет существующие правила профиля и боя. Application владеет результатом IO, защитой источника и транзакциями ручных изменений. Presentation показывает состояние сохранения. TrialRunner получает явный снимок актуального GameBalance.

**Tech Stack:** Unity 6000.5.7f1, C#, существующие Core/Application/Presentation, uGUI и Unity Test Runner.

**Spec:** ../specs/2026-10-12-authored-drawings-design.md, раздел «Этап 1».

**Status:** Реализация разрешена новым полным заданием пользователя (attachment e82f62d9-4add-46a4-887d-180a35e5b2bc). Прежние поэтапные approval gates заменены непрерывным выполнением после проверок; общий план — 2026-10-12-full-album-loop.md.

## Global Constraints

- Сохранить альбом до 64 страниц, золото, постоянные открытия и четыре слота.
- Не изменять числа, текущие материалы/броню/подачу/цвета/экономику.
- Не переписывать сцену, не запускать миграцию рисунков, не выполнять push или публикацию.
- Ошибка чтения существующего профиля не разрешает автозапись стартовых данных поверх него.
- Проверки IO используют изолированный путь; профиль игрока не является тестовым стендом.

## Review Focus

- Исправный backup не должен замениться повреждённым primary при первом save после восстановления.
- Будущая версия и отказ доступа не должны восприниматься как новая игра и перезаписываться.
- Возврат false после уже выполненной покупки недостаточен: золото/альбом/слоты при ручной ошибке записи остаются прежними.
- Повтор записи заработанной награды не начисляет её второй раз и не сбрасывает профиль при переходе в мастерскую.
- Trial не мутирует переданный balance; обе стороны используют одинаковые актуальные определения и явные условия участка.
