# Контракты симуляции и перестройка под давлением

Цель: сохранить слои первого среза, закрепить правила строительства/времени/попаданий и воспроизводимо проверить большую орду в редакторе и Windows Player.

Исходный запрос: ревью из приложенного пользователем текста. Проверенные проблемы: mutable Session в Presentation, готовые препятствия до окончания стройки, мгновенная мортира, общий mutable world mesh, бесконтрольное уплотнение. Сохраняются Core без Unity, конфигурация-адаптер и пространственный индекс.

- [x] ReadModel: закрытый wrapper, value snapshots по индексу без полной копии орды; данные только для чтения между шагами одного потока.
- [x] Стройка: совместимые сегменты пропускаются, атомарное списание, повторная проверка, чертежи проходимы, завершение ждёт освобождения клетки, сохранение процента здоровья/фактических вложений.
- [x] Движение: оценка времени прохода и пролома, диапазоны текущего здоровья, один объединённый пересчёт, ограниченная очередь и фронт сегмента.
- [x] Бой: запуск/полёт/попадание мортиры в Core, урон по актуальным позициям, одна награда за смерть, фактический урон без overkill.
- [x] Время/события: ровно 30 Гц, ×2 числом шагов, максимум шесть догоняющих шагов и ограниченный долг, кольцевой буфер визуальных событий с номерами; экономика не зависит от потерь эффектов.
- [x] Отображение: отдельные статические конструкции, динамика, эффекты и preview с разными условиями обновления; траектория без самостоятельного урона.
- [x] Статистика: агрегаты оружия/простоя/экономики/потерь, ограниченные записи проломов, состав обороны и улучшения, пик врагов.
- [x] Регрессии Core/PlayMode, пространственный индекс против полного перебора, равные команды по номерам шагов при разных частотах кадров, чистый перезапуск.
- [x] Повторяемый сценарий: внешнее кольцо → пролом → внутренние батареи → победа, 3000 одновременно живых, команды рисования под давлением и обычная/двойная скорость.
- [x] Windows Development Player на текущем компьютере: профиль тяжёлых кадров/выделений/навигации/мешей и сохранённый отчёт. Текущий компьютер — измеренный локальный стенд, минимальная целевая машина пользователем не задана.
- [x] Документация точных контрактов, сценария, результатов и оставшихся ограничений.
