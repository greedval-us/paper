# Общий экран стендов: удалён

MechanicsHub, каталог маршрутов и команды **Validation → Open mechanics hub** / **Generate mechanics hub** удалены вместе с отдельными тестовыми сценами. Датированные отчёты об общем экране остаются историей соответствующих версий проекта.

Обе команды **Paper Defense → Game → Open player game** и **Paper Defense → Открыть игру** теперь открывают [PaperDefenseGame.unity](../Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity). Основной маршрут включает мастерскую, полигон и бой; это единственная сцена сборки.
