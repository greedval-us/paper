# Общий экран стендов

Откройте `Paper Defense → Validation → Open mechanics hub` и нажмите Play. Команда открывает `Assets/PaperDefense/Scenes/MechanicsHub.unity` в режиме Single; если в текущих сценах есть несохранённые правки, Unity предложит сохранить их. Отмена оставляет текущие сцены открытыми. Во время Play та же команда возвращает на общий экран.

На экране доступны все 27 стендов: 23 сцены механик и четыре сцены графики. Фильтры помогают выбрать нужную группу; «Все стенды» показывает полный список. Карточка содержит название и краткую инструкцию.

| Фильтр | Стендов |
|---|---:|
| Мастерская | 3 |
| Оружие | 7 |
| Модули | 4 |
| Враги и чернила | 5 |
| Игровые системы | 4 |
| Графика и анимация | 3 |

Нажатие на карточку открывает один стенд и выгружает предыдущую сцену. Кнопка «К стендам» возвращает на общий экран. Повторный вход начинает свежую проверку. Обычные стенды используют профиль в памяти; стенд профиля работает в собственном временном каталоге. Переходы сохраняют изоляцию от игрового профиля.

`Paper Defense → Validation → Generate mechanics hub` создаёт отсутствующий общий экран и обновляет его каталог из существующих сцен и `Scenario.asset`. Существующий файл общего экрана не перезаписывается. Каталог находится в `Assets/PaperDefense/Resources/Validation/MechanicsSceneCatalog.asset`. Общий экран расположен вне `Scenes/Tests`, поэтому в этой папке остаются 27 стендов.

В Unity Editor сцены загружаются напрямую по пути без изменения Build Settings. Для запуска в Player включите общий экран и все 27 сцен из каталога в отдельную сборку для разработки вручную.

Описание проверок механик находится в [руководстве сцен](Mechanics-Test-Scenes.md), а стендов графики — в [руководстве оформления](Notebook-Art.md).

Проверки запуска включают реальные кадры отрисовки после действий механик и включения радиусов. Строительство дополнительно проверяет стены, шипы, улучшение, стирание и сброс; совместный стенд — начало нового боя после возврата в мастерскую.
