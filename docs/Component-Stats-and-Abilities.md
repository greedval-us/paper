# Характеристики и способности деталей

**album-v1.0, 18.10.2026.** [Excel](balance/PaperDefense-Album-Balance-v1.xlsx) и [JSON](balance/album-balance-v1.json) содержат предлагаемый баланс. Это данные проектирования, не готовый импорт в Unity. Реальные исходные значения находятся в [runtime-снимке](audit/2026-10-17-album/current-runtime.json).

## Каталог

54 определения: 14 деталей основы (4 рамки, 3 корпуса, 3 брони, 2 подачи, 2 поворота); 7 механизмов; 18 оружейных деталей (7 штатных головок, 3 альтернативных ствола, 3 прицела, 3 магазина, 2 спуска); 15 частей сооружений (4 основания, 4 функции, 3 оболочки, 4 оснащения). Нейтральные варианты входят в каталог и стоят 0 золота.

У каждого семейства собственная штатная головка. Короткий/длинный ствол совместимы с пулемётом и пробоем; широкий — с мортирой. Спуск «очередь 3» — только пулемёт и штатная обойма. Совместимость проверяется по ID, категории и разъёму.

## Расчёт

Порядок: ID/версия → категория/совместимость → исходные значения → прибавки → произведение множителей → нагрузка/пределы → материал/цвет/усиления партии. Один модификатор учитывается один раз. Пиксели, масштаб и декоративные линии не являются входами расчёта.

| Величина | Формула |
|---|---|
| Нагрузка | Сумма нагрузки всех установленных экземпляров частей |
| Вместимость | Рамка + изменение корпуса |
| Цена | ceil((основа + оружие + модули) × материал) |
| Цена механизма | Текущая цена готового оружия минус сборочный кредит 16; повторно кредит не вычитать |
| HP | HP рамки × корпус × материал × усиления партии |
| Урон | Урон механизма × множители частей × материал/усиления |
| Дальность | Дальность механизма × ствол × прицел; минимум мортиры остаётся 6 |
| Обойма N | N механизма × магазин; спуск очереди явно заменяет на 3 |
| Цикл | (N−1) × интервал + перезарядка |
| Номинальный DPS | Урон × N / цикл, одна доступная цель без брони |
| Подача на ствол | min(1,25; множитель подачи; подача рамки × множитель / число действующих стволов) |
| DPS башни | Сумма DPS действующих оружий с учётом их доли подачи |
| Захват | 0,25 с × поворот × прицел |
| Эффективные HP | HP / (1 − общая защита); фронтальный сектор отдельно |
| Окупаемость насоса | ceil(цена / штрихи за полностью пережитую волну) |

Excel показывает однородные многопушечные сборки. В смешанной башне подача распределяется между реально действующими креплениями; нельзя делить DPS второй раз. Интервал и перезарядка масштабируются подачей одинаково. Первый выстрел — после захвата, затем N−1 пауз и одна перезарядка вместо завершающей паузы. Потеря/смена цели не восстанавливает обойму.

Генератор v1 допускает только карандаш. Штатный насос в ручке стоил бы 108 при максимальном доходе 96 за восемь волн; в маркере — 192. Эти заведомо убыточные варианты не предлагаются. Защиту насоса дают совместимые оболочка и панели; для них окупаемость рассчитывается отдельно.

Пулемёт: урон 12, интервал 0,42, N=6, смена 0,42 → 28,57 DPS. Очередь: N=3, интервал 0,189, смена 0,882 → 28,57 DPS. Барабан: N=12, интервал 0,357, смена 1,26 → 27,76 DPS. Меняется распределение попаданий во времени. Для N=1 период задаёт перезарядка, поэтому ствол меняет оба времени. Штатные варианты сохраняют текущую непрерывную скорострельность.

## Пределы и способности

Пробой: до 7 разных целей. Веер: до 8 в конусе 90°. Рикошет: 4 разные цели, переход до 3 клеток. Мортира: полёт 0,8 с к фиксированной точке, минимум 6, радиус 2,4. Число 8 для мортиры в книге — сценарное число целей для оценки, не скрытый лимит AoE. Промокашка: 0 урона, очистка клякс.

Времена конечны и положительны; действующий интервал не меньше 0,05 с; общая защита не выше 0,6; N — положительное целое. Нагрузка не превышает вместимость. Фронтальный щит даёт защиту 0,4 в секторе 90° направления основы, не по направлению каждого ствола. В обычную колонку защиты он не включён. Slow не перемножается: сильнейший эффект с нижней границей скорости 0,4.

Ремонт: одна ближайшая повреждённая постройка, tie-break по ID; не себя и не другие ремонтные посты. На одной цели применяется сильнейшая скорость, не сумма. Генератор: общий лимит 2, только штрихи, не золото/XP, без возврата. Он должен быть завершён на начало и жив на конец волны. Пара runId/waveId/entityId оплачивается один раз. Материал не усиливает доход/ремонт.

Зигзаг, волна и возврат не входят в v1. Новое поведение в первой версии обеспечивают семейства оружия, магазины, спуски и сооружения.

## Прогрессия и проверка

Уровень + золото + отсутствие ранее купленного права. Покупка постоянная, сохранение бесплатно. Полный каталог стоит 2115 золота. Полная победа: 94 золота и 120 XP; уровень 8 — 12 полных побед, все покупки — 23 при отсутствии иных трат. Выкуп всего каталога не обязателен.

Обычный насос: 60 штрихов, 12 за волну; экономичный: 72, 15 за волну и 68 HP вместо 80. Оба окупаются за 5 волн. В конце партии их постройка не должна рекламироваться как прибыльная.

Книга проверяет арифметику и базовые ограничения. Реальный бой зависит от overkill, движения, плотности, захвата и потерь попаданий. Финальная приёмка: одинаковые seeds и бюджеты 200/400/800, быстрые/плотные/защищённые цели; измерять пропуски, HP замка, урон, контроль и чистый ресурс. Универсальное превосходство во всех сценариях требует перенастройки. Значения нового каталога не называются финальным игровым балансом до этих прогонов.
