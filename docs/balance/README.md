# Баланс альбома v1.0

[Скачать Excel](PaperDefense-Album-Balance-v1.xlsx) · [машиночитаемый каталог](album-balance-v1.json) · [формулы и правила](../Component-Stats-and-Abilities.md).

**54 детали**: 14 частей основы, 7 механизмов, 18 частей оружия и 15 частей сооружений. В книге 11 листов: сводка восьми стартовых рисунков, башни, расчёт оружия, сооружения, прогрессия, четыре каталога частей, текущая игра и правила. Примеры: 11 оружий, 10 башен, 7 сооружений.

Начните со «Сводки». Цветные входные ячейки можно менять для подбора чисел; формулы пересчитывают зависимые сборки. Каталоги используют устойчивые ID. На «Прогрессии» меняются уровень, золото и флаг покупки; получение уровня само по себе золото не списывает. Изменения Excel не синхронизируются с JSON автоматически: утверждённые правки перенести в build-data.mjs и пересобрать комплект.

## Стартовая экономика

Восемь бесплатных рисунков стоят суммарно **426 штрихов** за по одной постройке. Из 640 остаётся 214. Детали стартового набора не требуют золота. Полная победа из восьми волн даёт 94 золота и 120 XP. Уровень 8 доступен после 12 таких побед; все платные детали стоят 2115 золота, то есть 23 полные победы без иных расходов. Это ориентиры темпа, а не требование купить весь каталог.

Ремонт обслуживает одну цель; один объект получает только сильнейший ремонт. Насосы ограничены двумя на поле, не возвращают ресурс при продаже и дают доход за волну, которую пережили полностью. Штатный насос 60/12 и улучшенный 72/15 окупаются за 5 волн. При постройке во время волны доход за неё не начисляется. Генератор v1 допускает только карандаш: цена 108 для ручки превышала бы весь доход 96 за партию. Защита повышается частями оболочки и оснащения.

## Что проверено

Книга построена через @oai/artifact-tool. [Протокол](workbook-validation.json): 1467 сравнений вычисленных ячеек с независимым расчётом, изменение урона с проверкой распространения, границы уровня/золота. [Скан формул](formula-scan.json) не нашёл ошибок. Все 11 листов [отрендерены](preview) для осмотра. Пересчёт в настольном Microsoft Excel не выполнялся.

Текущие числа получены [из действующей цепочки Player через Unity](assembly-runtime.json). Лист «Текущая игра» содержит активный каталог, правила и измеренные кампании. Аналитика DPS предполагает непрерывную доступную цель без брони; не включает путь, потери времени наведения, ответный огонь или эффект плотности врагов. [Приёмка задачи 14](../validation/modular-album/balance-report.md): 486 измеренных прогонов; ограничения и три тайм-аута seed 2026 записаны для задачи 15.

Условия приёмки: бесплатный набор проходим, нет обязательной покупки для ранних карт, варианты имеют различимые преимущества и недостатки, генератор выгоден только при достаточном горизонте, поддержка не заменяет атакующую оборону. Не усиливать все новые детали одновременно только ради роста уровня.

[Перебор допустимых сочетаний](analytical-validation.json): 62 рецепта оружия, 12 283 однородные башни и 27 сооружений. Все 54 детали достижимы, базовый DPS семи семейств сохранён. Это проверка совместимости и арифметики, не игровой прогон.
