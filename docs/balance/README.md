# Баланс составного альбома

Источники текущего баланса: авторский каталог [album-balance-v1.json](album-balance-v1.json), игровые assets PlayerBalance → PlayerRules → PlayerContent → PlayerAssemblyCatalog и [runtime-экспорт](assembly-runtime.json). Экспорт отражает состояние на момент его создания; после изменения assets его нужно обновить. Формулы описаны в [параметрах компонентов](../Component-Stats-and-Abilities.md).

Авторский источник — `Tools/AlbumDesign2026/build-data.mjs`. Он создаёт числовой JSON, который `AlbumBalanceImport` импортирует в Unity. `BalanceWorkbookExport.ExportPlayerAssembly()` выгружает фактические параметры производственного resolver. Независимые Node-проверки сравнивают числа, ID и рецепты с экспортом. [Команды](../../Tools/AlbumDesign2026/README.md).

Каталог содержит 91 определение, включая 36 частей сооружений. Сумма цен открытия всех деталей составляет 3793 золота. В мастерской отдельно продаются шиповая ловушка за 45 золота с уровня 1, маяк наводки за 80 с уровня 2 и чернильная призма за 120 с уровня 3. Цены семейств берутся из `WorkshopProfile.GetStructureOffer`. Аналитический DPS рассчитан для постоянно доступной цели без брони. Путь, наведение и плотность врагов учитывает игровая симуляция.

`assembly-runtime.json` выгружает базовые правила и рецепты до применения `MissionBalanceFactory`. Его исторические `startingInk=640`, восемь базовых волн и обычная награда fixture не заменяют выбранную страницу кампании. Девять карт, их стартовые бюджеты и реальные боевые исходы проверяет отдельный [валидатор кампании](../Campaign.md#проверки).

## Генерируемые результаты

`verify-balance.mjs` записывает `analytical-validation.json`. `build-workbook.mjs` создаёт Excel, `workbook-validation.json`, `formula-scan.json` и `preview/`. Это результаты генерации, а не входные источники игры. Excel не импортируется обратно в Unity; старые книги и превью не нужны для проверки текущего каталога. Новый результат требует свежих входных данных и собственного протокола проверки. [Сохранённые проверки и ограничения](../validation/README.md).

Обязательные входы инструментов в этом каталоге: `album-balance-v1.json` и `assembly-runtime.json`. `balance-data.json` — отдельный экспорт сравнительных пресетов для [инструмента совместимости](../../Tools/BalanceWorkbook/README.md); он не заменяет Player runtime-экспорт и перед генерацией сравнительной книги обновляется из Unity.

В редакцию `album-v1.4` вошла спаренная кассета мортиры. Пороги уровней и цены позволяют покупать боевые детали после каждого первого прохождения. Чернильной призме принадлежат штатные площадка и линза, складная колыбель и собирающая огранка. Параметры линзы задают радиус поля, урон ожога и множитель скорости. Команда `node Tools/AlbumDesign2026/verify-balance.mjs --design-only` проверяет авторскую арифметику перед импортом и записывает `runtimeVerified:false`. Для сверки с игрой запустите верификатор на свежем Unity-экспорте. Сохранённые рецепты используют числовые снимки своей редакции.
