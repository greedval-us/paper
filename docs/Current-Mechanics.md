# Что реализовано в текущем проекте

26.10.2026. [Дизайн](Game-Design.md), [план](superpowers/plans/2026-10-18-modular-album-implementation.md), [баланс](validation/modular-album/balance-report.md), [приёмка выпуска](validation/modular-album/release/acceptance.md). Аудит 17.10.2026 описывает историческую базу.

| Область | Действующее поведение |
| --- | --- |
| Игра | Меню → карта → подготовка восьми слотов → восемь волн → результат; пауза, приоритет и межволновые улучшения |
| Состав | 54 определения деталей, точные ID/ревизии, совместимость, нагрузка, подача и физические стыки |
| Мастерская | Готовые части основы и каждого оружия, сравнение через единый resolver, сохранение снимка |
| Альбом | Общие страницы башен/сооружений, до 64 страниц, восемь выбранных ID и библиотека компонентов |
| Профиль | Writer v8; readers v1–v7 сохраняют страницы/права, будущие данные защищены от перезаписи |
| Открытия | XP/уровень и отдельная однократная покупка за золото |
| Оружие | Пулемёт, пробой, мортира, веер, рикошет, степлер и промокашка; обоймы, очереди и перезарядка |
| Сооружения | Баррикада, замедлитель, ремонт и генератор из четырёх категорий, в тех же восьми слотах |
| Ремонт | Одна повреждённая цель на пост; сильнейший эффект без суммирования на одной цели |
| Генератор | Карандаш, лимит два, доход за полностью пережитую волну, без возврата и повторных выплат |
| Награды | Транзакции и квитанции; полная победа даёт 94 золота и 120 XP |
| Полигон | Производственная симуляция атак/поддержки с заданными seed/бюджетом, без профильных наград |
| Графика | Общий набор в стиле эскизов; результаты полного переноса — в отчётах задачи 13 |
| Старые данные | Drawing/Freeform и геометрические DTO нужны историческим readers; интерактивный редактор удалён |

Один экземпляр восьми бесплатных страниц стоит 426 штрихов; из 640 остаётся 214. [Экспорт Player](balance/assembly-runtime.json) отражает PlayerBalance → PlayerRules → PlayerContent → PlayerAssemblyCatalog. Excel содержит 11 листов и сверяется с действующим resolver.

Волна завершается после подкреплений, врагов и снарядов. Дальнобойный плевун может стоять за пределами башен и непрерывно повреждать восстанавливаемую постройку. Штатное стирание/перестройка меняет оборону и позволяет разорвать равновесие. Автоматическая стратегия приёмки учитывает этот выход и записывает возврат ресурса; боевые характеристики ради завершения теста не менялись.

Свежие тесты/XML, исходы seed 2026, хеши и build-report приведены в [отчёте выпуска](validation/modular-album/release/acceptance.md). Пользователь выбрал скрытый запуск; GPU-тайминги и GC bytes/frame недоступны. В дымовом сценарии измерены CPU и фактические количества сборок GC; FPS плотного боя не заявляется.
