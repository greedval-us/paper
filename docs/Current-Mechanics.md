# Что реализовано в текущем проекте

Состояние рабочего дерева на 18.10.2026. [Аудит и доказательства](audit/2026-10-17-album/report.md) · [целевая модель](Game-Design.md) · [план](superpowers/plans/2026-10-18-modular-album-implementation.md).

| Область | Реализовано | Нужно для новой модели |
|---|---|---|
| Игра | Основная сцена, карта 96×64, оборона замка, восемь волн, награды | Сохранить цикл, добавить XP и однократное начисление новых наград |
| Мастерская | Стандартная башня: основа → оружие → проверка; старые страницы доступны для чтения | Полные категории частей и мастерская сооружений |
| Каталог | 4 основы, 7 семейств оружия, 4 модуля | 54 части, совместимость по категориям, версии рецептов |
| Альбом | Сохранение в профиле v7, 64 страницы, четыре боевых слота | Общий тип башни/сооружения, 8 слотов, миграция |
| Открытие | Покупки за золото | XP, уровень и проверка двух условий |
| Оружие | Кулдаун, подача, пробитие, площадь, веер, рикошет, slow, очистка | Обойма и перезарядка; спуск очереди |
| Сооружения | Отдельные строительные инструменты: стена, ловушки, замедление, ремонт | Рецепты в альбоме; первый набор без ловушек; новый генератор |
| Ремонт | Максимальная доступная скорость применяется к каждой повреждённой цели в радиусе | Одна ближайшая цель на пост, без суммирования постов |
| Ресурс | Начальные штрихи, награды волн, фиксированные чернильницы | Составной насос, общий лимит 2, доход за полную волну |
| Графика | Общий атлас; пилот составного пулемёта на обычной основе | Остальные части, стыки, свободный ход и полный UI |
| Полигон | Конечные сценарии через настоящее ядро оружия, без наград | Новые рецепты и проверка поддержки/экономики отдельно |

Свободный редактор снят с стандартного игрового маршрута. Типы Drawing/Freeform, геометрия мортиры, веера и направленной брони ещё существуют для старых страниц и тестов. Они не задают новые способы создания объекта. Данные совместимости описаны в [Content-Profile-Compatibility](Content-Profile-Compatibility.md).

В текущем ядре волна завершается после всех подкреплений, врагов и снарядов. Пауза Application останавливает симуляцию. Выбор межволнового усиления останавливает отсчёт следующей волны, но сам по себе не равен паузе всех систем. Этот порядок важно учитывать при начислении дохода генератора.

Аудит выполнил 939 EditMode/Editor и 66 выбранных PlayMode-тестов. Это не полный PlayMode-прогон, не Windows build и не измерение FPS. Новая проектная модель этими тестами ещё не покрыта.
