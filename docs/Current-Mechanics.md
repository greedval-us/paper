# Что реализовано в текущем проекте

[Дизайн](Game-Design.md), [баланс](Balance-Parameters.md), [боевое развитие](Field-Modernization.md), [реестр проверок](validation/README.md).

| Область | Действующее поведение |
| --- | --- |
| Игра | Меню → три тетради → одна из девяти карт → подготовка восьми слотов → миссия → результат; тактическая пауза, приоритет и платная модернизация отдельных башен |
| Состав | 91 определение, включая 36 частей сооружений. Детали имеют ID и ревизию, правила совместимости, нагрузку, подачу и физические стыки |
| Мастерская | Башни: основа → оружие → сборка → проверка. Сооружения: семейство → детали → проверка. Единый resolver, сравнение до установки |
| Альбом | Общие страницы башен/сооружений, до 64 страниц, восемь выбранных ID; библиотека начинает со стандартной основы и трёх оружий |
| Боевые наборы | До 12 именованных составов по восемь мест: сохранить текущий, применить целиком, обновить, переименовать и удалить на экране подготовки; пустые места сохраняются |
| Продолжение миссии | В паузе между волнами — «Сохранить и выйти»; на главной — продолжить ту же попытку с полем, ресурсами, модернизацией и статистикой на тактической паузе |
| Интерфейс | Адаптивные колонки и ограниченные каталоги, подробности по нажатию, постоянная навигация, Escape, hover/выбор/фокус и плавные переходы |
| Боевое развитие | Четыре направления 0–III, шесть обычных шагов и один III; постоянный цвет экземпляра I–III; цена и 2/3/4 с работ, технологии по сохранённым победам |
| Профиль | Writer v11; readers v1–v10 сохраняют страницы/права, будущие данные защищены от перезаписи; старый файл копируется перед первым commit новой версии |
| Открытия | Последовательные страницы, детали за первую победу, XP/уровень и однократная покупка за золото; ранги II за победу 1-1, III за 1-3 |
| Оружие | Пулемёт, пробой, мортира, веер, рикошет, степлер и промокашка; сменные обойма, ствол, прицел, крепление; очереди и перезарядка |
| Сооружения | Баррикада, замедлитель, ремонтная мастерская и генератор доступны сразу. Шиповая ловушка, маяк наводки и чернильная призма требуют однократной покупки чертежа за золото |
| Шиповая ловушка | Пропускает врагов. При контакте бьёт по всем целям в радиусе и повторяет удар через секунду, если в зоне остаются враги |
| Маяк наводки | Помечает защищённых врагов в радиусе. Метка уменьшает защиту и держится ещё секунду после выхода из поля. При наложении меток и зелёных чернил действует сильнейшее ослабление |
| Чернильная призма | Чередует красный ожог, синее замедление и зелёное ослабление брони. При наличии врагов штатная призма выпускает импульс раз в 2 секунды в радиусе 3 клеток |
| Ремонт | Одна повреждённая цель на пост; сильнейший эффект без суммирования на одной цели |
| Генератор | Карандаш, лимит два, доход за полностью пережитую волну, без возврата и повторных выплат |
| Награды | Награда выбранной миссии за волны, завершение и первую победу; прогресс, звёзды, открытия и абсолютная квитанция фиксируются одной транзакцией |
| Полигон | Производственная симуляция атак/поддержки с заданными seed/бюджетом, без профильных наград; базовый по умолчанию, явные изолированные ранги входят в повтор |
| Графика | Тёмная клетка, «Полевой штаб», составная «Бумажная механика» (`paper-mechanisms-v4`) и «Чернильная стая»: шесть разных ролей врагов, замок, окружение и эффекты через общий native renderer; компактные силуэты для толп >1000 |
| Старые данные | Drawing/Freeform и геометрические DTO нужны историческим readers; интерактивный редактор удалён |

Ресурсы, карта и волны задаются выбранной [страницей кампании](Campaign.md). [Экспорт Player](balance/assembly-runtime.json) отражает базовую цепочку PlayerBalance → PlayerRules → PlayerContent → PlayerAssemblyCatalog; MissionBalanceFactory создаёт из неё отдельный снимок миссии. Числовая сверка деталей использует JSON и производственный resolver.

Волна завершается после подкреплений, врагов и снарядов. Дальнобойный плевун может стоять за пределами башен и непрерывно повреждать восстанавливаемую постройку. Штатное стирание/перестройка меняет оборону и позволяет разорвать равновесие.

[Реестр проверок](validation/README.md) содержит результаты запусков и их ограничения. Новые башни строятся без выбора материала и цвета; глобальные улучшения отключены. Явные legacy fixtures сохраняют старые материалы/окраску, а сооружения — укрепление материалом (кроме генератора).
