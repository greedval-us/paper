# Путь игрока и перенос интерфейса

**Главное меню, карта и подготовка (01–03) перенесены по эскизам, общий бумажный стиль собран частично.** Экраны 04–28 сохраняют прежнюю компоновку. Целевой вид описан в [дизайне игры](Game-Design.md), точный статус — в [порядке реализации](Implementation-Roadmap.md).

В меню живые кириллические подписи и пять действий: «Играть» открывает карту, «Мастерская» — редактор, «Настройки» и «Помощь» — соответствующие страницы, «Выход» — подтверждение закрытия игры. Кнопки поддерживают клавиатурный фокус; компоновка адаптируется к 16:9, 4:3 и масштабу интерфейса до 150%.

Карта показывает текущую миссию, реальные волны, прочность замка, стартовые штрихи и чернильницы. В подготовке все четыре карточки стоят в один ряд; материал, готовность и запуск доступны без прокрутки. При уменьшении окна сокращается декоративная часть, подписи остаются читаемыми. Карта тоже без прокрутки: в компактном виде повторная миниатюра замка скрыта, большой рисунок поля и полная сводка сохранены.

«Заменить» открывает альбом для выбранного слота; четыре вкладки позволяют переключить слот. Применение заменяет страницу по действующим правилам уникальности, отмена сохраняет прежний набор. Растущий список альбома прокручивается внутри своего окна. Стартовый набор — одиночное и двойное орудие, пробойник и бронированная мортира; пользовательские рисунки показаны собственной геометрией, цены и характеристики берутся из игровых данных.

## Целевой маршрут по эскизам

| Шаг | Действие игрока |
|---|---|
| Главное меню | «Играть» открывает карту; мастерская, настройки и помощь доступны отдельно |
| Карта «Первый рубеж» | Просмотреть поле и условия текущей миссии, перейти к подготовке |
| Подготовка | Выбрать четыре разные страницы альбома и один начальный материал; при необходимости открыть мастерскую |
| Мастерская | Основа → Оружие → Рисунок → Проверка; сохранить страницу или вариант, испытать конструкцию |
| Альбом | Явно назначить сохранённые страницы в четыре слота; отмена не меняет прежний набор |
| Бой | Расставить оборону, запустить волну, управлять инструментами, ресурсами и приоритетами |
| Пауза и усиления | Выбрать действие без ввода строительства сквозь окно |
| Результат | Увидеть настоящие итоги, награды и состояние записи; повторить попытку или вернуться на карту |

Сохранение чертежа и начало боя — разные действия. Выход из мастерской возвращает к подготовке. Полигон относится к испытанию конструкции, не выдаёт наград и не заменяет основную миссию. Заготовки, мортира, веер и броня остаются частями мастерской.

При недостатке золота, ошибке рисунка или отказе записи интерфейс должен назвать причину и доступный следующий шаг. Черновик не скрывается за ложным сообщением об успехе. Выход из незаконченного боя требует явного предупреждения.

## Что уже есть в технической основе

[PlayerGameRoot](../Assets/PaperDefense/Presentation/Player/PlayerGameRoot.cs) управляет страницами Home, Map, Preparation, Workshop, Battle, Pause, Upgrades, Result, Settings и Help. Существуют мастерская, редактор, альбом, полигон, одна карта и восьмиволновая партия. Главное меню, карта и подготовка уже обновлены; композиции мастерской, боя и остальных экранов ещё предстоит перенести по эскизам.

Штрихи тратятся в попытке на строительство, золото хранит постоянные открытия, цветные чернила дают эффекты. Цены и характеристики читаются из [игровой конфигурации](../Assets/PaperDefense/Configuration/Game). Профиль сохраняет альбом, открытия и набор страниц; незаконченный бой для продолжения не сохраняется. [Правила профиля](Content-Profile-Compatibility.md).

## Запуск текущей игры

Открой [PaperDefenseGame.unity](../Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity) через **Paper Defense → Game → Open player game** или **Paper Defense → Открыть игру**, затем Play. Обе команды ведут в единственную игровую сцену; технические сцены и отдельные стенды удалены.

**Paper Defense → Game → Build player game** создаёт `Builds/PlayerGame/PaperDefense.exe` для Windows x64. Переносить нужно всю папку PlayerGame с Data и DLL. Аргумент `-paper-memory-only` запускает без чтения и записи личного профиля. [Подробности разработки](Development-Guide.md).

## Управление существующей основы

| Ввод в бою | Действие |
|---|---|
| 1–4 | Выбор страницы боевого набора |
| 5–8 | Стена, шипы, смола, ремонтный пост |
| ЛКМ / протягивание | Размещение или линия строительства; выбор объекта по контексту |
| ПКМ | Отмена текущего жеста |
| Q | Переключение материала |
| C / B | Окраска / промокашка |
| E / U | Стирание / улучшение |
| P | Приоритет цели выбранной под курсором постройки |
| Tab | Радиусы |
| Space / Esc | Пауза игровой оболочки; Esc также закрывает доступные окна |
| F / N | Темп / следующая волна |
| Колесо / СКМ | Приближение / перемещение камеры |

Подсказки и экран помощи при переносе должны соответствовать реально доступным командам и состоянию игры. Пауза, подтверждения и выбор усиления блокируют боевой ввод.
