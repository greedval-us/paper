# Игровая сборка — первый срез

Отдельная сцена: `Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity`.

Запуск в редакторе: **Paper Defense → Game → Open player game**, затем Play. Сборка Windows: **Paper Defense → Game → Build player game**. Исполняемый файл: `Builds/PlayerGame/PaperDefense.exe`; при переносе нужна вся папка PlayerGame, включая Data и DLL.

## Доступный маршрут

Меню → карта «Первый рубеж» → четыре чертежа и начальный материал → восемь волн → реальные итоги. Из меню и подготовки доступна мастерская: альбом, сборка деталей, свободный рисунок, назначения в набор и существующий полигон. Выход из мастерской ведёт к подготовке, не начинает бой немедленно.

Иконки основных действий имеют подсказки при наведении и фокусе с клавиатуры. Подписи характеристик, выбор деталей и числовые цены остаются текстом. Основные действия мастерской также получили иконки, сохранив существующие обработчики.

В бою доступны четыре чертежа, стена, шипы, смола, ремонтный пост, ластик, улучшение, промокашка и окраска. Панели показывают настоящие ресурсы, состояние чернильниц, будущую волну и текущие показатели. Пауза, настройки и выбор улучшения блокируют строительство и скрытые команды боевого UI.

| Управление | Действие |
|---|---|
| 1–4 / 5–8 | Чертежи / обычные постройки |
| ЛКМ / провести ЛКМ | Поставить башню / нарисовать линию |
| Q / E / U | Материал / ластик / улучшение |
| C / B / P | Окраска / промокашка / приоритет |
| Колесо / СКМ | Масштаб / сдвиг поля |
| Tab | Радиусы |
| N / F | Запустить волну / темп |
| Space / Esc | Пауза; повторное нажатие продолжает |
| ПКМ | Отменить строительный жест |

Настройки первого среза: полноэкранный режим и дальность башен. Профиль использует существующее хранилище золота, альбома и открытий. Незаконченный бой не сохраняется; возврат на карту и повтор завершают текущую попытку. Для проверки без изменения своего профиля запускай exe с `-paper-memory-only`.

## Стенды и перенос изменений

Сцены `Scenes/Tests`, `MechanicsHub.unity`, прежняя `PaperDefense.unity` и `NotebookGame.prefab` не изменены. Они доступны через прежнее меню Validation. В список сцен Windows-сборки включён только игровой вход.

Игровой набор данных хранится в `Configuration/Game`: `PlayerBalance.asset`, `PlayerRules.asset`, `PlayerContent.asset`. Это самостоятельные копии проверенного набора Target на дату среза. Создание сцены и сборка не перезаписывают их экспериментальными данными. Сначала проверяй настройки на стендах, затем осознанно переноси одобренные изменения в игровой набор и проверяй игровой маршрут.

14.10.2026 игровой `PlayerRules` получил отдельную числовую настройку цен, оружия, поддержки и восьми волн. Старт теперь640штрихов; Target сохраняет прежние числа. [Таблицы до/после, роли сборок и воспроизводимые проверки](validation/2026-10-14-numeric-balance/report.md).

Код механик общий: новая оболочка вызывает `RunController`, не содержит второй симуляции или собственной экономики. Изменение общего кода действует в обоих режимах после компиляции; сцены и копии настроек не заменяют ветки Git для изоляции экспериментального кода. Будущие механики следует подключать в игровом наборе только после проверки.

## Оформление и границы

Направление взято из предоставленных концептов: тетрадный лист, синие чернила, рисунки башен, замок и свободное пространство вокруг элементов управления. Фон меню — отдельная иллюстрация; управление и игровые показатели отрисовываются в Unity. Боевые объекты используют существующую графику проекта. Это первый рабочий срез с одной картой: дополнительных миссий, достижений, новой экономики и звука пока нет. Мастерская переиспользует проверенный редактор; её полная художественная переработка остаётся отдельным этапом.
