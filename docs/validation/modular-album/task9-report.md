# Задача 9 — мастерская, состав, открытия и библиотека

База: `af9592b`. Unity `6000.5.7f1`.

## Реализация

- Настроенная игровая мастерская открывает новый составной маршрут: основа → оружие → проверка либо семейство сооружения → состав → проверка. Явные исторические стенды без составного каталога сохраняют прежний Wizard. Альбом, меню и подготовка задачи 10 здесь не перерабатываются.
- `WorkshopDraftSession` владеет локальными неизменяемыми снимками. В основе и оружии пять категорий, в сооружении четыре. Отмена не меняет родителя. «Сохранить и выбрать» публикует компонент и меняет родителя только после успешной транзакции профиля; отказ записи оставляет вложенный черновик. Сооружение принимает состав локально и сохраняется отдельной страницей, без выдуманного типа библиотеки сооружений.
- Готовые основы и семь механизмов дополняются раскрытием состава. При смене механизма явно заменяются только несовместимые категории на доступные штатные части; остальные части сохраняются. Очередь с барабаном остаётся недопустимым кандидатом до отдельного выбора штатного магазина.
- Каталог фильтрует совместимость, отдельно раскрывает недоступные детали, показывает требования уровня и золота, доплату постройки и нагрузку. Покупка подтверждается отдельно: уровень 4, 94−80=14. Право общее для совместимых каталогов; покупка ничего не устанавливает. Для магазина отдельно показаны объём, интервал и время смены из resolver.
- Библиотека основ и оружия показывает состав, позволяет выбрать и удалить запись с подтверждением. Выбор копирует её снимок; дальнейшее удаление библиотеки не ломает собранную страницу. Сохранение страницы и варианта использует команды задачи 5, включая границы имени 48/49 и альбома 64/65.
- Числа берутся из Core. `AssemblyPreviewMetrics` повторно использует тот же расчёт для цены, нагрузки, вместимости, HP и времени постройки при перегрузе. Это отдельный тип данных без разрешённого боевого снимка: обычный resolver продолжает возвращать `Value == null`. На проверке видны реальные числа и именованные вклады частей; сохранение и полигон недоступны.
- Переключение маршрутов хранит два независимых незавершённых черновика. Вложенный редактор требует сохранения или отмены перед сменой маршрута. Обновление золота/статуса не пересоздаёт активное поле имени. Удаление UI во время клавиатурного Submit отложено до безопасного момента.
- Добавлены 165 ключей русского текста с контрактами аргументов. Прежние вручную исправленные тексты сохранены.

## Границы этапа

Сохранён строгий физический gate задачи 5. Полное авторское покрытие стыков и графики запланировано задачей 13: сейчас для неподтверждённых рецептов показана конкретная диагностика, сохранение и полигон блокируются. Сертифицированный пулемётный пилот рисуется по точному snapshot через `WeaponAssemblyGraphic`; остальные изображения явно подписаны «Схема семейства». Уже принадлежащие профилю стартовые сооружения сохраняют возможность строительства, проверенную задачами 7–8. Общий полигон сооружений относится к задаче 12. Побитное совпадение с концепт-артом и Player build здесь не заявляются.
