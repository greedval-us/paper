# Задача 2: единый расчёт характеристик сборок

Дата: 18.10.2026. План: [задача 2](../../superpowers/plans/2026-10-18-modular-album-implementation.md). База: `5a67046`, ветка `codex/standard-workshop-stage1`. Unity 6000.5.7f1, открытый редактор, сцена PaperDefenseGame.

## Результат

- Добавлены `AssemblyResolver`, `AssemblyValidation`, `AssemblyResolution`, неизменяемые `ResolvedEntry`, `ResolvedWeapon`, `ResolvedSupport` и отдельный `LegacyAlbumAdapter`.
- `Resolve(recipe, catalog, balance, material)` проверяет точные ID/revision и совместимость, считает исходные значения, прибавки, произведения множителей и ограничения, затем применяет выбранный материал. Ошибка возвращает диагностику и `Value=null`.
- `Resolve(snapshot, balance, material)` использует только определения из сохранённого снимка. Изменение/удаление исходного библиотечного объекта, переход каталога на другую ревизию и последующие изменения mutable balance не меняют уже выданный результат.
- `TowerCatalog.ResolveEntry` и `WorkshopReadModel.PreviewAssembly` подготовлены для смешанных страниц. Составные страницы используют собственный snapshot; legacy сохраняет прежний расчёт, последовательность модификаторов и исторический приоритет `balance.Content`. Пользовательский маршрут ещё не переключён.
- Считает стоимость, HP, нагрузку, вместимость, время постройки, общую/фронтальную защиту, оружие и поддержку. Механизмы не получают повторное вычитание кредита 16.

Для карандаша стартовые башни имеют цены **40 / 64 / 60 / 99**, HP **55**, нагрузку **4 / 8 / 6 / 9**. Сооружения: **16/200, 22/55, 65/70, 60/80** (цена/HP). Короткий пулемёт: **36 / 10,8 урона / 6,4 дальности / 0,357 с**; длинный: **52 / 13,2 / 10 / 0,504 с**.

## Контракты расчёта

- `ResolvedWeapon.Interval` и `ReloadSeconds` — собственные времена оружия без подачи. `IntervalAtFeed` и `ReloadAtFeed` учитывают её один раз; минимум действующего интервала применяется после деления на подачу. Цикл: `(N−1)×Interval+Reload`, включая случай N=1.
- `ResolvedEntry.Dps` — предпросмотр при всех работающих креплениях. `FeedForActiveMounts` позволяет боевой системе учесть реально действующие стволы, не деля итоговый DPS повторно. Предел подачи нового альбома — 1,25.
- Защита ограничена 0,6; фронтальная защита хранится отдельно с сектором 90° и не прибавляется к обычным эффективным HP. Slow выбирает сильнейшее значение с нижним пределом скорости 0,4.
- Базовые HP/вместимость сооружения берутся из основания, радиус/скорость — из функции. Нейтральные Set=0 других частей не стирают базу. Материал не усиливает ремонт и доход. Генератор допускает только карандаш, максимум 2, возврат 0.
- Цена считается через decimal-представления конечных authoring-float перед ceil. Это даёт 40×3,2=128 вместо ошибочных 129 при прямом расширении двоичного float в double. Legacy-арифметика сохранена.
- Материал преобразует только финальные показатели. Цвет и усиления партии остаются последующими существующими стадиями симуляции: утверждённый интерфейс resolver не принимает их состояние.

В спецификации нет новой формулы суммарного времени башни: сохранено `max(времена оружий) + задержка дополнительного крепления + сумма времени основы`, затем материал. Для сооружения суммируются времена четырёх частей. Длительность замедления после выхода 0,6 с задана явным v1-default, поскольку в JSON она пока присутствует только в заметке; заметки во время игры не разбираются. Геометрические посадки/clearance остаются задачей 3.
