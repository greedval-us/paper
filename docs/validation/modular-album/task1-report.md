# Задача 1: каталог деталей и рецепты

Дата: 18.10.2026. План: [Составной альбом, задача 1](../../superpowers/plans/2026-10-18-modular-album-implementation.md). База выполнения: `159c450`, ветка `codex/standard-workshop-stage1`. Unity 6000.5.7f1, текущий открытый редактор, сцена PaperDefenseGame.

## Результат

- Импортирован `PlayerAssemblyCatalog.asset`: баланс `album-v1.0`, 54 определения с revision=1, группы 14/7/18/15, 8 бесплатных стартовых страниц. ID исходного JSON сохранены.
- Core содержит типизированные категории, семейства, числовые модификаторы, ссылки на точную ревизию, рецепты основы/оружия/сооружения, смешанную страницу и независимые снимки состава. Геометрия посадок остаётся задачей 3.
- `ComponentCatalog.TryGet(id, revision, out definition)` не подставляет другую ревизию. Коллекции снимка защищены от изменения исходных массивов и вложенных authoring-данных.
- `AlbumBalanceImport.Validate`, `Preview`, `Import` явно переводят проектный JSON в типы. Предпросмотр показывает добавления, изменения, удаления и изменения стартовых страниц. Ошибочный или неполный JSON отклоняется до изменения asset. Повторный импорт сохраняет GUID и данные.
- В меню редактора добавлены **Paper Defense → Content → Preview assembly balance import / Import assembly balance**. Используется уже установленный Newtonsoft.Json, только в Editor; новые пакеты не добавлялись.
- В `PlayerContent.asset` добавлена только ссылка `assemblyCatalog`. Его прежние данные и GUID сохранены. Новый каталог ещё не включён в пользовательский маршрут; профиль и симуляция остаются на прежних интерфейсах.

## Решения и ревью

- Отрицательное `gold` недопустимо; отрицательные `cost/load/build/capacityAdd` скидочных деталей сохранены по спецификации.
- `core.mortar.targets=8` сохранено как оценочный сценарий; runtime TargetLimit=0 означает отсутствие искусственного лимита целей по площади. Веер получает типизированный угол 90°.
- Требование `trigger.burst → magazine.standard` задано явно; игровые правила не читают русские заметки.
- Для Unity inline-сериализации введён тег варианта рецепта. Пустые сериализованные объекты допускаются, заполненный альтернативный payload отклоняется.
- Независимое read-only ревью нашло два P2 и замечание точности целых: все исправлены и проверены красными/зелёными тестами. Числа JSON читаются с invariant culture, целые поля — без промежуточного float.
