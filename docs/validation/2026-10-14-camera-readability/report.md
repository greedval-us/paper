# Камера и читаемость карты — 2026-10-14

Причина медленного колеса: активный Input System возвращает нормализованный шаг `1`, а старый коэффициент `exp(delta × 0,0015)` был рассчитан на старый диапазон. Регрессионный тест воспроизвёл изменение `2 → 2,003002` за один щелчок. На общей карте контуры толщиной 0,015–0,04 клетки попадали в доли экранного пикселя; мелкая сетка и бумажная фактура добавляли рябь.

Изменения:

- ×1,28 за щелчок; диапазон ×1–×4, дробные шаги трекпада, центрирование на курсоре, ограничение краями карты.
- Экранная минимальная толщина контура и аналитическое сглаживание штрихов; рисунки и боевые размеры остаются исходными.
- Крупная сетка на общем плане, плавное появление мелкой при приближении; экранная толщина сетки постоянна.
- Обзорные обозначения башен за всей геометрией построек; HP не тоньше двух пикселей.
- Настройки вынесены в `Assets/PaperDefense/Resources/NotebookViewSettings.asset`.

## Визуальная проверка

Главная сцена, 1280×720, отдельный профиль только в памяти, восемь башен, кольцо баррикад, первая волна с 24 живыми врагами. Проверяются общий план ×1, приближение, работа колеса и игнорирование прокрутки над HUD. Изменённая для проверки сцена не сохраняется.

Проба ввода в игровом Dynamic update: один шаг `1 → 1,28`; на приближённом виде `2,56 → 3,2768`, ошибка удержания точки под курсором — `0`. Прокрутка над панелью чернильниц, расположенной внутри viewport камеры, оставляет `3,2768` без изменений. На общем плане удержание курсора ограничивается границами карты: ось, по которой весь лист уже помещается, остаётся по центру. Ошибок в Unity Console после проверки нет.
