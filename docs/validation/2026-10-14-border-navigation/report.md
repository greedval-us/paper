# Движение с верхнего и нижнего края — 2026-10-14

В `WeightedFlowField.Next` одинаковые стоимости соседних клеток разрешались порядком обхода `+X, -X, +Y, -Y`. На свободной местности северные и южные враги поэтому шли вдоль края до колонки цели, а затем строились в общий поток.

Поле теперь запоминает актуальную цель при пересчёте. При строго одинаковой стоимости выбирается соседняя клетка с меньшим расстоянием до этой цели по прямой. Главный критерий — время пути с учётом здоровья укреплений — сохранён. Движение остаётся по соседним клеткам, без срезания углов гор и баррикад. Случайность и дополнительные пересчёты поля путей не добавлены.
