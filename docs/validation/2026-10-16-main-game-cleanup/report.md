# Очистка проекта до основной игры — 16 октября 2026

Оставлена игровая сцена `Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity`. Оба пункта открытия игры ведут в неё, Build Settings содержит только эту включённую сцену. Шаблон URP в `Assets/Settings/Scenes` остаётся шаблоном редактора и не входит в игру.

Удалены 27 тестовых стендов, MechanicsHub, прежняя техническая PaperDefense и отдельная ContentAcceptance — всего 30 сцен. Удалены их генераторы, маршрутизаторы, настройки, каталог Resources, демонстрационный prefab и код стендов. Убран автоматический запуск PressurePlayerProbe и два PowerShell-скрипта его запуска.

Два acceptance-скрипта перемещены в Validation с сохранением GUID и пространства имён; приемочные данные используются тестами без отдельной сцены.
