# Экран 04 — контракт переноса

Продолжение утверждённого альбома от 16 октября; объём этого шага — только «Основа». Экраны оружия, рисунка, проверки и альбома сохраняют свою текущую композицию.

## Исходное состояние

- Unity 6000.5.7f1, `Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity`, runtime uGUI.
- Выделенный объект редактора отсутствовал. Активный UI: `Player workshop / Workshop HUD / Workshop paper`.
- Canvas: Screen Space Overlay, sortingOrder 100; CanvasScaler ScaleWithScreenSize, Expand. `WorkshopResponsiveLayout` владеет размерами и перекомпоновкой общего листа. Сцена создаёт UI программно.
- До изменений: `before-foundation.png`, настоящий Game View 1600×900. Console: 0 ошибок и предупреждений.
- Старый внешний ScrollRect переставляет карточки и общую сводку. Для шага 0 он будет скрыт: каталог получает собственный viewport, основные переходы остаются снаружи прокрутки.

На 1024×768 обе основные области остаются рядом, шаги занимают отдельную строку. Шрифты, подписи и карточки подстраиваются под ширину. Дополнительное пространство заполняется бумагой.

## Ассеты и поведение

Проверенные ресурсы: `NotebookAtlas.png`, `NotebookSprites.json`, ключи `chassis.standard`, `chassis.heavy`, `chassis.precision`, `chassis.battery`. Спрайты показываются целиком. После замечания пользователя о недостатке деталей добавлены прозрачные растровые `FoundationPageDecor` и `FoundationPreviewScenery`: нижний пейзаж, ели, камни, трава, флаг и руины вокруг выбранного корпуса. Источники и точные промпты: `ArtSource/Notebook/NewStyle/foundation-generation.json`, навык `imagegen`, встроенный инструмент. Игровые подписи и числа остаются UI.

Истина для карточек — разрешённый `run.Content`, включая overrides PlayerRules, а не только исходный PlayerContent. Выбор меняет только черновик. Покупка использует существующее подтверждение и запись профиля, не выбирает деталь автоматически. Неудачная запись оставляет золото, права и черновик прежними. Переход к подготовке не запускает бой.

Визуальный анализ и окончательная проверка снимков — основной агент; независимые агенты проверяют документацию/контракты, пишут регрессионные тесты и отдельную верхнюю навигацию, не управляя Unity. Проверки: пять разрешений, длинный текст, выбор, недоступность, подтверждение/отмена/отказ записи, переходы и существующие тесты мастерской. Окончательные снимки имеют префикс `foundation-detail-`; предыдущая упрощённая версия не считается визуальной приёмкой.
