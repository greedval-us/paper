# Журнал проверок

В таблице приведены результаты прежних запусков на Unity 6000.5.7f1. Дата указывает, какую версию игры проверяли. Команды для повторной проверки текущей версии приведены в [руководстве по тестированию](../Testing.md) и [руководстве по сборке](../Development-Guide.md).

| Дата | Область | Результат |
| --- | --- | --- |
| 03.11.2026 | Модернизация и кампания | Прошли 1712 тестов EditMode. Симуляция с оплатой построек и модернизаций завершила девять миссий и 59 волн. |
| 03.11.2026 | Карты, подготовка, мастерская и полигон | Прошли 1101 тест PlayMode и восемь отдельно запущенных визуальных сценариев. Windows Release собран с тремя предупреждениями. |
| 13.11.2026 | Первая переделка | Прошли 156 целевых тестов PlayMode, затем 24 теста после правки кнопки пропуска. Проверены установка длинного ствола, испытание, сохранение и назначение башни. |
| 13.11.2026 | Разбор поражения | Прошли 274 целевых теста EditMode и 65 PlayMode. Замеры потери здоровья замка и числа выстрелов дополнительно проверили в бою до поражения. |
| 13.11.2026 | Сохранение и продолжение миссии | Целевые прогоны охватили 486 проверок симуляции и 287 проверок игровых переходов. Файловый профиль загрузили повторно между запусками Play Mode. Перезапуск самостоятельной Windows-сборки в этот сценарий не входил. |

## Данные для инструментов

Миграция каталога читает [исходные шаблоны](content/before/templates.json). Генератор [сравнительной книги](../../Tools/BalanceWorkbook/README.md) читает семь сохранённых входов:

- Результаты [EditMode](content/after/editmode-tests.json) и [PlayMode](content/after/playmode-tests.json).
- [Сравнение с исходными данными](content/after/baseline-comparison.json) и [изменения данных](content/data-only-diff.json).
- Приёмка [в редакторе](content/after/editor-acceptance.json) и [в собранной игре](content/after/player-acceptance.json).
- [Результат сборки для разработки](content/after/development-build.json).

В опубликованных данных путь сборки и пути двух временных профилей указаны относительно проекта. Игровые результаты и параметры сохранены. Полные журналы и снимки можно получить локально по [инструкции тестирования](../Testing.md).
