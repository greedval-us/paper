# История проверок

Эта папка хранит доказательства отдельных изменений: JSON/XML/CSV, изображения и отчёты с датами. Число прошедших тестов, характеристики сборки и время кадра относятся к указанному в отчёте состоянию проекта. Они не подтверждают автоматически текущее рабочее дерево.

Актуальное описание функций — в [общем указателе](../README.md), порядок нового запуска — в [руководстве разработчика](../Development-Guide.md).

## Более ранние этапы

[Первоначальная проверка](verification-2026-10-11.md), [контракты](verification-contracts-2026-10-12.md), [рефакторинг ядра](verification-core-refactor-2026-10-12.md), [полный альбом](verification-full-album-2026-10-12.md), [мастерская](verification-workshop-2026-10-12.md), [модульные башни](2026-10-12-modular-verification.md), [форма мортиры](verification-mortar-footprint-2026-10-12.md) и [исторический баланс](2026-10-12-stage5-balance.md) сохраняют свои исходные условия и выводы. Они могут описывать старые версии профиля, правила качества и числа, которых больше нет в текущем игровом пресете.

Для нового отчёта указывайте дату, версию Unity, исходный пресет/сцену, команды, seed, выполненные проверки, результат и ограничения. Различайте статическую сверку, тесты ядра, PlayMode и запуск отдельного Player. Сохраняйте новые доказательства отдельно, не заменяя исторические результаты.
