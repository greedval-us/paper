# Проверки основы и служебные данные

Эскизы ещё не реализованы в игре. Сохранённые здесь результаты относятся к существующей технической основе, а не к переносу будущего интерфейса.

## Последняя проверка игровой основы

[Очистка основной игры — 16 октября 2026](2026-10-16-main-game-cleanup/report.md): 878 EditMode- и 457 PlayMode-тестов, проверка сохранённой игровой сцены, Windows-сборка и сохранность эскизов. Это результаты того запуска; обновление документации не является новым запуском Unity-тестов.

## Обязательные входные файлы инструментов

Старые отчёты стендов, промежуточные прогоны и снимки интерфейса удалены. Восемь исторических JSON сохранены, потому что существующие инструменты читают их напрямую. Они не подтверждают текущий баланс или реализацию эскизов.

| Файлы | Зачем сохранены |
|---|---|
| [before/templates.json](content/before/templates.json) | Входной снимок для однократной миграции `ContentDatabaseMigration` |
| [editmode-tests](content/after/editmode-tests.json), [playmode-tests](content/after/playmode-tests.json) | Исторические данные о приёмке контента, которые читает генератор книги баланса |
| [baseline-comparison](content/after/baseline-comparison.json), [editor-acceptance](content/after/editor-acceptance.json), [player-acceptance](content/after/player-acceptance.json), [development-build](content/after/development-build.json) | Остальные исторические входы того же генератора |
| [data-only-diff.json](content/data-only-diff.json) | Исторический вход генератора книги баланса |

Устаревшие готовые JSON/Excel-выгрузки из `docs/balance` удалены. Для новой книги сначала выполните экспорт в Unity, затем генератор по [инструкции](../../Tools/BalanceWorkbook/README.md). Источник текущих значений — игровые assets.

Старый `content/code-freeze.json` удалён как не соответствующий нынешнему коду. Новая проверка `Validate-ContentDataOnly.ps1` начинается с `-Mode Freeze`, затем выполняется `-Mode Verify` в рамках того же нового эксперимента; прежний результат приёмки не подменяет этот цикл.

После реализации экранов создавайте отдельный датированный отчёт: соответствующие эскизы, версия исходников, реально выполненные проверки, снимки Unity, результаты и оставшиеся различия. Сохраняйте отдельно результаты проверки самих макетов и проверки работающей игры.
