# Перезарядка, независимый захват и сообщение редактора

Основа: чистый commit `1c3bdc8`. Unity `6000.5.7f1`. Пользователь отдельно разрешил изменение этих трёх поведений после рефакторинга.

## Изменения

- **Core:** перезарядка продвигается до проверки цели и ограничена одним готовым действием. Незавершённые перезарядки делят подачу; готовое крепление без цели освобождает долю. Между волнами `GameSession` вызывает только продвижение готовности, без выстрелов и очистки; нулевой шаг остаётся паузой.
- **Core:** каждый ствол хранит свой таймер захвата и проверяет фактическую цель после действия предыдущего. Смена цели мортиры не задерживает пулемёт. Наведение применяется к каждому захвату; промокатель сохраняет независимую очистку без боевого захвата.
- **Presentation:** причина отказа показана отдельно от качества рисунка. Обычные обновления, инструмент, масштаб и пустые операции её сохраняют. Успешные штрих, стирание, undo/redo, очистка части или новая сессия очищают сообщение. Событие `Edited` отделяет успешное изменение от `Changed` для перерисовки.

Слои `Presentation → Application → Core` сохранены. Core остаётся без Unity и IO (`noEngineReferences: true`); UI-состояние не внесено в ядро. Параметры двух пресетов и расчёты 168 сборок совпали с предыдущей проверкой ([снимок правил](combat-drawing-fixes-rules.json)). Сцены, prefab, конфигурационные assets, asmdef и формат профиля не изменены.
