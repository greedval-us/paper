# Этап 2, первый срез — общие крепления стандартных башен

17.10.2026 · Unity 6000.5.7f1. Общие точки посадки текущих цельных спрайтов; полный пилот отдельных частей A3/A4 остаётся следующим срезом.

## Что изменено

Большой предпросмотр оружия, миниатюра, альбом, полигон, строительство и бой используют `NotebookMountLayout` через `NotebookTowerComposition`. Дублирующие вычисления крыши/опоры удалены из `WeaponAssemblyGraphic`. Места принадлежат основе и имеют постоянные номера: снятие среднего оружия не сдвигает слоты 0 и 2. Батарея рисуется в порядке 1 → 0 → 2, без изменения ID для прицеливания и отдачи.

Отдельный `Resources/Art/NotebookMounts.json` schema 1 хранит разметку четырёх основ и семи оружий. Позиции/диаметр посадки основы заданы относительно принятого исходного crop; attach и muzzle оружия — в пикселях полного авторского холста. Trim и область атласа не переопределяют этот холст. Числа размечены явно по существующему исходнику; автоматический поиск alpha bounds не используется. Размер оружия нормируется по диску опоры, масштаб остаётся равномерным. Прицеливание учитывает диагональную ось исходного ствола attach → muzzle.

Визуальное дуло проходит тот же transform, что спрайт, включая отдачу. Поза берётся из состояния крепления, а не из отдельного луча веера или удлинённого пробивающего луча. Core продолжает считать бой от центра клетки; `SegmentOrigin` переносит к дулу только этот исходный sentinel. Продолжения рикошета остаются в записанной точке предыдущего попадания.

Миниатюра и крупный осмотр используют общие границы с запасом на поворот и максимальную штатную отдачу. Масштаб не меняется во время наведения; броневые сектора следуют за корнем основы. Явные native-замены оружия в специальных темах сохраняют прежние локальные единицы и дуло.

## Совместимость

Core, DTO, корневая схема профиля v7, баланс, цены и права не менялись. `DrawingTemplateCatalog` сохранён. PlayerDrawing/Freeform используют прежнюю геометрию и трансформы; стандартный каталог к их линиям не применяется. Тесты диска используют уникальные временные пути, визуальные fixtures — memory-only. Личный профиль не открывается.
