# Экран 05 — контракт переноса

Продолжение утверждённого альбома, только «Мастерская → Оружие». Основа уже перенесена; рисунок, проверка и специальные редакторы сохраняют текущие команды и композиции.

Исходная сцена: `Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity`, Unity 6000.5.7f1, runtime uGUI, Screen Space Overlay, CanvasScaler Expand. Начальный снимок — `before-weapons.png`. Рабочая база — `bbebb37`. Выделение редактора пустое; игровых ошибок при начале нет.

Источник — `ArtSource/Notebook/References/2026-10-16/screens/05-weapons.png`, 1672×941. Игровые цифры не копируются из примеров PNG.

Владельцы: `WorkshopResponsiveLayout` — доступный лист и общий масштаб; `WizardWeaponHeader` — восстановимое оформление навигации; `WizardWeaponPanel` — композиция регионов и карточек; `WeaponAssemblyGraphic` — фактическая сборка. Минимум листа — 1024×850 логических пикселей с сохранением пропорций окна; это сохраняет целый лист и место для закрытых карточек на низком окне.

После замечания пользователя нижняя полоса уточнена: три отдельные карточки с иллюстрациями, названиями «Броня башни», «Подача», «Особая форма» и полями выбранного значения со стрелкой. Они открывают действующие настройки. Растровое оружие стыкуется с крышей через координаты площадок и центров опор в исходном рисунке; игровые точки стрельбы не меняются. Для авторского рисунка сохраняются его собственные привязки.

Ассеты: отдельные спрайты оружия и основы из NotebookSpriteCatalog; подробное окружение FoundationPreviewScenery и нижний пейзаж FoundationPageDecor из предыдущего шага. Подписи и числа остаются текстом UI. Новая растровая генерация не нужна для этого шага.

Выбор меняет только активное крепление черновика. Покупка и выбор раздельны. Первое крепление обязательно; лишние крепления после смены основы можно очистить. Пустой рисунок не блокирует переход от корректной сборки к рисованию. Все виды оружия, включая промокашку, доступны по каталогу.
