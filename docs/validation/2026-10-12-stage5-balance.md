# Целевой пресет — этап5

Unity6000.5.7f1. Свежие проверки после исправления полигона:238 EditMode и105 PlayMode,0ошибок/пропусков. Отдельный RED воспроизвёл обход защиты ответным огнём: ожидалось488HP, было470HP; полигон теперь вызывает тот же `DamageRules.StructureDamage`, что обычный бой.

`NotebookBalance.asset` остаётся историческим. Его независимая копия `TargetNotebookBalance.asset` включает целевые настройки и используется существующим `NotebookGame.prefab`; существующая сцена наследует эту ссылку. Сцена не пересоздавалась, профиль игрока не использовался.

Новые числа — настраиваемые гипотезы: старт720штрихов; нулевые доход от времени и бонус раннего запуска; выплаты волн140/160/180/200/220/240/260/280 (всего1680), плюс конечные награды врагов. Ручные выплаты волн имеют приоритет. «Бережливость» сохраняет разовые60штрихов/возврат и повышает выплаты волн×1.25 вместо пассивного дохода. При спавне враг получает конечный расходуемый бюджет; передача потомкам сохраняет сумму.

Материал сохраняет цену, HP, строительство и возврат, урон×1. Броня даёт25%защиты вместоHP×1.5; общий предел60%. Общая производительность основания1.6 делится только между работающими креплениями; готовность ограничена одним действием. Цветовой бюджет всей башни — три разные живые поражённые цели за1с; обычный урон сохраняется. Снаряд несёт захваченные при запуске параметры эффекта. Слабое воздействие не продлевает сильное.
