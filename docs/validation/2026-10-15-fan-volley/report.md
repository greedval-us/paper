## Поведение

Проверены фиксированное число снарядов и остаток распределения, общий поворот направлений, сохранение авторских изгибов, копирование входных данных, ограничения углов и точек. Боевые тесты проверяют концентрацию шести снарядов, промахи боковых направлений, отсутствие пробития при одновременном убийстве, обычную защиту целей и общий бюджет цветового эффекта. Проба запускает тот же боевой код для одной выбранной установки.

PlayMode-проверки охватывают доступ из мастерской, рисование через настоящие события указателя, ошибочный повторный штрих, очистку пробы, отмену ошибки без потери принятой схемы, удаление/отмену, закрытие во время жеста. Сохранение проверяется через временный JSON-профиль: авторские точки, копии, варианты, смена оружия и запрет перезаписи будущей версии схемы. Временные профили изолированы от пользовательского сохранения.

Два регрессионных сценария сначала воспроизвели дефекты и затем прошли: отмена ошибочного штриха удаляла принятую схему; замена схемы через общий `WithAssembly` могла возвращать старый экземпляр. Оба исправлены. Полный первый EditMode-прогон показал 936/937: новая проверка цвета ошибочно использовала бесцветный режим пробы. Она переведена на обычный боевой запуск; игровая логика для этого не менялась.

Независимое ревью модели, боя, хранения и UI не выявило дополнительных существенных дефектов.
