# Excel механик и баланса

1. В Unity выполните `Paper Defense > Export mechanics and balance JSON` или вызовите `PaperDefense.Editor.BalanceWorkbookExport.Export()`.
2. В корне проекта выполните `Tools/BalanceWorkbook/Build.ps1`.
3. Проверьте `docs/balance/PaperDefense-Mechanics-Balance.xlsx`. `workbook-validation.json` сохраняет хэш данных, результат сверки формул и ограничения проверки.

Экспорт читает обе настройки через `CreateWorkshopBalance()`, включая Target, генерацию угроз и значения по умолчанию. Он не меняет настройки, профиль или текущую партию. JSON версии 2 содержит глобальные правила, эффективные каталоги по ID, configured/effective механики и эталоны `TowerCatalog`. Для каждой записи каталога сохранены источник и факт переопределения пресетом. Отдельный каталог приёмки не включается в основной баланс.

Девять листов показывают границы механик, формулы сборки, оружие, основания, модули и эффекты, материалы и врагов, волны, глобальные параметры, полные поля каталога с контурами и источники. Новые записи отображаются автоматически. Числа боя, испытаний и оценки рисунка поступают из подготовленных данных Unity.

Генератор использует только `@oai/artifact-tool` из bundled workspace runtime. `node_modules` — локальная junction, исключённая из Git. Если код, content assets, пресеты или сам генератор изменились после экспорта, генератор останавливается и требует новый экспорт Unity. Числа баланса не копируются в генератор. Финальные результаты тестов берутся из `docs/validation/content/after/editmode-tests.json` и `playmode-tests.json`.

В книге нет игрового переключателя механик. Лист «Механики» описывает developer configuration для следующего запуска. Значения Excel не импортируются обратно в Unity.
