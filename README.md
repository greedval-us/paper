# ДЕРЖИ ЛИНИЮ

Tower defense на тетрадном листе. Игрок собирает альбом составных башен и сооружений, выбирает **8 рисунков** и защищает замок. В мастерской соединяются готовые детали. Новые детали открываются по уровню и однократно покупаются за золото.

В Unity работают составные башни и сооружения, профиль v8 с сохранением старых страниц, восемь общих слотов, опыт, библиотека компонентов и покупки деталей. Основа графики — эскизы тетрадного альбома. Свободный редактор выведен из пользовательских маршрутов. [Приёмка Windows-сборки](docs/validation/modular-album/release/acceptance.md) содержит результаты, ограничения и порядок запуска.
