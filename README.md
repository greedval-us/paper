# ДЕРЖИ ЛИНИЮ

Игровой прототип tower defense на тетрадном листе для **Unity 6000.5.7f1**. Нарисуйте оборону, направьте поток каракулей в простреливаемые коридоры и переживите восемь волн с финальной осадой. Единственный ресурс — **штрихи**.

## Запуск

Готовая Windows x64 development-сборка находится в `Builds/Windows/PaperDefense.exe`. Запускайте её вместе с соседними папками и DLL.

1. Откройте этот каталог как проект Unity и дождитесь импорта и компиляции.
2. Выполните **Paper Defense → Создать или открыть прототип**: команда создаёт сцену, настройки баланса и префаб игры.
3. Откройте `Assets/PaperDefense/Scenes/PaperDefense.unity` и нажмите **Play**.
4. В режиме планирования нарисуйте стены, поставьте башни и запустите следующую волну кнопкой HUD или клавишей **N**.

Настройки находятся в `Assets/PaperDefense/Configuration/NotebookBalance.asset` (`GameBalanceAsset`): меняйте их в Inspector до запуска партии. Игровое ядро получает отдельную копию данных.

## Управление

| Действие | Управление |
|---|---|
| Выбрать стену / пулемёт / пробивающую пушку / мортиру / шипы | **1 / 2 / 3 / 4 / 5** |
| Нарисовать стену или полосу шипов | Зажать левую кнопку мыши, провести линию, отпустить |
| Поставить выбранную башню | Щелчок левой кнопкой мыши |
| Переключить материал: карандаш → ручка → фломастер | **Q** |
| Ластик / улучшение постройки | **E / U**, затем щелчок по постройке |
| Пауза / продолжение | **Space** |
| Следующая волна | **N** |
| Переключить скорость | **F** |
| Начать новую партию | **R** |
| Показать дальность оружия | **Tab** |
| Переключить приоритет башни под курсором | **P** |
| Отменить текущую линию | **Escape** |
| Приблизить или отдалить лист | Колёсико мыши |
| Перемещать приближённый лист | Средняя кнопка мыши |

Панель на листе дублирует основные команды и показывает стоимость. Улучшение оплачивается разницей цен материалов; возврат при стирании зависит от материала и оставшейся прочности. После второй, четвёртой и шестой волны выберите одно из трёх улучшений.

Линия строится целиком либо отклоняется без списания. Повторные клетки и совместимые сегменты не оплачиваются дважды. На паузе можно оплатить чертёж; он начнёт строиться после продолжения. Пока рисунок не готов, враги проходят через него. Если враг оказался в клетке к завершению стены, чертёж ждёт освобождения. Улучшение сохраняет процент прочности и тоже требует времени. Мортира стреляет в выбранную точку с задержкой: быстрый враг может уйти из взрыва.

## Что входит в прототип

- Одна карта, восемь волн, победа и поражение, планирование, пауза и ускорение.
- Рисуемые стены и шипы; три оружия с одиночным, линейным и площадным поражением.
- Три материала построек и три роли врагов: массовый, быстрый и осадный.
- Общая карта стоимости пути: замкнутая стена разрешена, но враги могут пробить её.
- Процедурная графика тетради и каракулей, HUD на русском языке.
- Отдельное ядро на C#, ограниченный интерфейс чтения для графики, тесты контрактов, статистика партии и воспроизводимый сценарий на 3 000 одновременно живых врагов.

Это первый законченный игровой срез. Кампания, сохранение партии, постоянная прогрессия, дополнительные карты, звук и полный набор механик исходной концепции ещё не реализованы. Баланс — исходные настройки для игровых тестов. Сценарий на 3 000 врагов помогает измерять нагрузку; он не гарантирует частоту кадров на конкретном компьютере.

## Код и проверка

Исходники находятся в `Assets/PaperDefense`. Зависимости направлены от представления через приложение к независимому ядру. Подробности и точки расширения описаны в [архитектуре](docs/PaperDefense-Architecture.md).

Проверку правил запускайте через **Window → General → Test Runner → EditMode**, проверку ввода, часов и связей компонентов — через **PlayMode**. Команда **Paper Defense → Проверить орду 3000** проверяет естественный пролом замкнутого внешнего рубежа, строительство внутренних батарей во время боя и победу. Отчёт `docs/validation/pressure-replay.json` содержит конфигурацию, seed, команды по шагам и сравнение обычной/двойной группировки шагов.

Для измерения собранной игры запустите Windows Player с аргументами `-paper-pressure -pressure-speed 1 -pressure-report <полный путь.json>`. Повторите с `-pressure-speed 2`. Не вводите ручные команды во время автоматического сценария. Измеряются настоящие кадры полной сцены, GC, шаги ядра, перестройки пути и сборка геометрии; отчёт сохраняет параметры компьютера и тяжёлые кадры. Это отдельная нагрузочная конфигурация, не баланс обычной партии.

Результаты выполненных проверок: [отчёт](docs/validation/verification.md). Команда **Paper Defense → Проверить все 8 волн** использует обычные команды и заработанные ресурсы, сохраняет покупки и исход каждой волны в `docs/validation/campaign-smoke.json`.

После усиления контрактов прошли **57 EditMode + 14 PlayMode** тестов. Оба реальных Windows-прогона на ×1/×2 достигли 3000 живых врагов и победы с одинаковым отпечатком состояния. Точные измерения, компьютер и ограничения приведены в отчёте.
