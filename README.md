# ДЕРЖИ ЛИНИЮ

Tower defense на тетрадном листе: собрать башню, нарисовать корпус и стволы, сохранить чертёж в альбом и защитить замок четырьмя выбранными конструкциями.

**Перенесены главное меню, карта и подготовка (эскизы 01–03), общий визуальный набор собран частично.** В Unity используются тёплая клетчатая бумага, синие чернила, живой текст и состояния кнопок. Карта и подготовка помещаются на экране без прокрутки, четыре карточки набора стоят в один ряд. Мастерская и экраны 04–28 ещё предстоят; полный статус — в [порядке реализации](docs/Implementation-Roadmap.md).

Визуальное направление: тёплая клетчатая бумага, рисунок синей ручкой, короткие русские подписи, крупное поле и холст, компактные панели. Путь игрока: меню → карта → подготовка → бой → результат; мастерская включает шаги **Основа → Оружие → Рисунок → Проверка**, альбом и полигон.

Эскизы определяют композицию. Числа, цены, ограничения и сохранение берутся из действующих игровых данных и правил, а не из подписей на растровых изображениях. Расхождения между альбомами разобраны в [описании источников](docs/design/README.md).

## Запуск существующей основы

1. Открой проект в **Unity 6000.5.7f1**, версия зафиксирована в [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt).
2. Открой [PaperDefenseGame.unity](Assets/PaperDefense/Scenes/Game/PaperDefenseGame.unity) или **Paper Defense → Game → Open player game**. Меню **Paper Defense → Открыть игру** ведёт туда же.
3. Нажми Play. Игра откроется в новом главном меню; «Играть» ведёт к карте и подготовке по эскизам.

**Paper Defense → Game → Build player game** создаёт Windows x64 в `Builds/PlayerGame/PaperDefense.exe`. Аргумент `-paper-memory-only` запускает игру без личного профиля. В сборке одна игровая сцена; тестовые и технические сцены удалены.
